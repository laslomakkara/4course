# Обработка ошибок и уведомления

Запуск:

```powershell
npm start
```

Откройте `http://localhost:3003`.

Если оставить название или email пустым, либо ввести неверный рейтинг, появится красное окно ошибки с подсказкой. При отмене изменённой формы появится предупреждение. После сохранения появится синее информационное окно.

Проверка:

```powershell
npm test
```
