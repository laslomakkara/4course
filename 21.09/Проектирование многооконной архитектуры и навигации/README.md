# Проектирование многооконной архитектуры и навигации

Откройте `index.html` в браузере.

- `MainWindow` — экран реестра партнёров с кнопкой «Добавить партнера».
- `PartnerEditWindow` — экран карточки партнёра с кнопкой «Назад».

Экраны переключаются без перезагрузки страницы, поэтому заполненные поля формы сохраняются при возврате в реестр. Заголовок вкладки меняется между `CRM: Реестр партнеров` и `CRM: Карточка партнера [Редактирование]`.

Проверка логики навигации:

```powershell
npm test
```
