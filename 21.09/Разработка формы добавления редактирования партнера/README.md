# Форма добавления и редактирования партнера

Откройте `index.html` в браузере. На странице есть все поля из задания, подсказки для телефона и email, а также кнопка возврата.

Чтобы открыть вариант редактирования, добавьте к адресу `?partnerId=14`. Заголовок вкладки поменяется на режим редактирования.

Проверка:

```powershell
npm test
```
