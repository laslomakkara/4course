# Интеграция формы с БД

Запустите приложение:

```powershell
npm start
```

Откройте `http://localhost:3002`.

Кнопка «Добавить партнера» открывает пустую форму. Нажатие на карточку партнера открывает заполненную форму. После сохранения список обновляется сам.

Проверка кода:

```powershell
npm test
```
