# CRM: Список партнеров и скидок

Откройте `index.html` в браузере.

Интерфейс содержит логотип и favicon из папки `resources`, заголовок страницы и три карточки партнёров. Широкий контейнер, двойные рамки, крупные карточки, цветные иконки партнёров и расположение скидки соответствуют приложенному макету.
