# Наполнение интерфейса, отладка и стресс-тестирование

Финальная сборка объединяет HTML-интерфейс и SQLite API. Карточки партнёров формируются в браузере из ответа `GET /api/partners`, а скидка поступает из функции первого задания.

## Демонстрационный запуск

```powershell
npm start
```

Откройте `http://localhost:3001`. Будут отображены четыре партнёра, включая партнёра без истории продаж с отображаемой скидкой `0%`.

## Стресс-тест

```powershell
npm run stress
```

Запуск заполняет базу до 100 партнёров. Откройте `http://localhost:3001` и убедитесь, что карточки прокручиваются и страница остаётся отзывчивой.

## Автоматическая проверка

```powershell
npm test
```

Тесты проверяют API, вывод нулевой скидки при отсутствии продаж, загрузку интерфейса и стрессовый набор из 100 партнёров.
