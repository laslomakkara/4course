# Расчеты и алгоритмы

В `business_logic.js` находятся две функции для бэкенда.

`calculatePartnerDiscount` получает сумму количества продаж из таблицы `sales_history` и возвращает скидку от 0% до 15%.

`calculateMaterialQuantity` получает коэффициент продукции и процент брака из таблиц `product_types` и `material_types`. При неверном ID, нулевом количестве или отрицательных параметрах функция возвращает `-1`.

Для проверки создаётся временная база с данными из предыдущего ETL-задания. Все SQL-запросы используют placeholders `?`.
