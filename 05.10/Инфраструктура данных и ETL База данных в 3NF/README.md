# Инфраструктура данных и ETL

В папке находится база данных SQLite в нормальной форме. Сущности разделены на таблицы `partners`, `products` и `sales_history`. Таблица истории продаж хранит только ссылки на партнера и товар, поэтому данные не дублируются.

`schema.sql` создаёт таблицы с внешними ключами, обязательными полями и уникальными значениями ИНН и email. Для денежных значений используются `DECIMAL`.

Скрипт `etl.js` очищает пробелы, приводит даты к формату `ГГГГ-ММ-ДД` и не загружает продажу, в которой указан несуществующий партнер `999`.

Команды:

```powershell
npm run etl
npm test
```

После импорта рядом со скриптом создаётся `clean_storage.db`. Файл не добавляется в Git, потому что его можно получить повторным запуском ETL.
