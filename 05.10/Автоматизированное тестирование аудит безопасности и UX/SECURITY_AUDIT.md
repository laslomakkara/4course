# Проверка SQL-запросов

Проверен код в папке `../Разработка UI навигации и CRUD форм`.

Значения, получаемые от пользователя, не вставляются в текст SQL. В запросах для чтения, добавления и изменения партнера используются плейсхолдеры `?` и передача параметров через `get`, `run` или `all`.

Например, имя партнера, email, телефон и идентификатор передаются отдельно от SQL-запроса. Поэтому текст вроде `'); DROP TABLE partners; --` сохраняется как обычное название партнера, а не выполняется базой данных.

В приложении нет текстового поиска. Служебный SQL для создания таблиц и миграций использует заранее заданные строки, а не введенные пользователем данные.
