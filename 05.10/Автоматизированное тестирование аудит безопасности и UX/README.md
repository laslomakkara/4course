# Автоматизированное тестирование, аудит безопасности и UX

В `material_calculator.test.js` находится шесть тестов для расчета материалов. Они проверяют обычный расчет, округление вверх, неправильные типы продукции и материала, отрицательный параметр и нулевое количество.

Для запуска:

```powershell
npm test
```

Проверка SQL-инъекций описана в `SECURITY_AUDIT.md`. Интерфейс CRM из соседней папки дополнен окнами ошибки, предупреждения и успешного сохранения.
