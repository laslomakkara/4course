# CRM: интерфейс и CRUD

Это приложение продолжает ETL-задание. При первом запуске оно создаёт `crm.db` из очищенных CSV и добавляет поля карточки партнера.

Есть три страницы:

- `MainWindow` с реестром партнеров
- `PartnerEditWindow` для добавления и редактирования
- `PartnerHistoryWindow` с историей продаж

После сохранения приложение возвращает в реестр и заново загружает данные из базы. Кнопки «Назад» сохраняют выбранного партнера через параметр адресной строки.

Запуск:

```powershell
npm start
```

Откройте `http://localhost:3020`.

Проверка:

```powershell
npm test
```
