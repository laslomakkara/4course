# Модульное тестирование и аудит безопасности

В файле `material_calculator.unit.test.js` находятся пять unit-тестов для метода расчета материалов: обычный расчет, округление, неверные ID, отрицательные размеры и нулевое количество.

В `security_audit.md` записан результат проверки SQL-запросов формы партнеров. Все пользовательские значения передаются через placeholders `?`.

При исключении в API калькулятора запись с датой, временем и текстом ошибки добавляется в файл `app.log` рядом с `server.js` предыдущего задания.

Проверка:

```powershell
npm test
```
