# Аудит безопасности

Проверен код добавления и редактирования партнеров из задания за 21.09.

Все запросы к SQLite создаются через `database.prepare(...)`. Значения передаются отдельными аргументами в `.get(...)` или `.run(...)`. Например, поиск типа партнера использует запрос `SELECT id FROM partner_types WHERE name = ?`, а создание партнера использует placeholders `?` для каждого поля.

Конкатенации пользовательского текста со строками SQL не обнаружено. Поэтому ввод имени, адреса, телефона и email не может изменить структуру SQL-запроса.

В текущем калькуляторе при исключении сервер записывает в `app.log` дату, время и текст ошибки. Файл исключён из Git, так как он создаётся во время работы приложения.
