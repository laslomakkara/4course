# CRM: история реализации продукции

Это следующая версия CRM из прошлых заданий. Здесь есть список партнеров, добавление и редактирование карточки, а также история продаж.

Запуск:

```powershell
npm start
```

Откройте `http://localhost:3005`. Выберите партнера и нажмите «История продаж». Для изменения данных дважды нажмите на карточку партнера.

При первом запуске рядом с сервером создаётся файл базы `crm_history.db`. Он не добавляется в Git, потому что содержит рабочие данные приложения.

В окне истории выводятся продукция, количество и дата продажи. Данные берутся из SQLite через SQL-запрос с `JOIN`. В базу также добавлены таблицы для типов партнеров, продукции и истории продаж. Связи между ними хранятся через внешние ключи.

Проверка:

```powershell
npm test
```
