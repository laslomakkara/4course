# Расчет материалов

Метод `calculateMaterialQuantity` рассчитывает, сколько сырья понадобится на производство.

В файле `material_calculator.js` заданы два справочника-мока:

- коэффициенты типов продукции
- проценты брака материалов

Расчет выполняется так: сначала определяется расход на единицу продукции, затем он умножается на количество изделий и увеличивается на процент брака. Итог округляется вверх с помощью `Math.ceil`.

Если идентификатор не найден, количество не является положительным целым числом или один из параметров не положительный, метод возвращает `-1`.

Проверка:

```powershell
npm test
```
