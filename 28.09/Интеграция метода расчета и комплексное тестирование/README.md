# Интеграция расчета материалов

Это экран калькулятора заказа для CRM. Он использует метод `calculateMaterialQuantity` из предыдущего задания, а не содержит вторую копию формулы.

Результат показывается на странице. Если метод возвращает `-1`, пользователь видит сообщение с перечнем того, что нужно проверить. Ошибка не останавливает работу формы.

Запуск:

```powershell
npm start
```

Откройте `http://localhost:3010`.

Проверка:

```powershell
npm test
```
